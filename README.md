## 1. Project Overview

El proyecto consiste en realizar una evaluación funcional independiente del sitio web de SÚPER KOMPRAS, utilizando pruebas manuales para comprobar el comportamiento de diferentes secciones de la plataforma.

La evaluación se realizó desde la perspectiva de un usuario, sin acceso al código fuente ni a documentación interna del sistema.

El objetivo fue verificar el funcionamiento de las categorías de productos, la navegación del catálogo y el acceso al carrito de compras.

## 2. Problem Identified

Se identificó la necesidad de evaluar la experiencia de navegación y el comportamiento de las funcionalidades principales de una plataforma comercial.

Se consideró importante comprobar que las categorías fueran accesibles, que el catálogo respondiera correctamente y que el usuario pudiera acceder al carrito sin experimentar errores funcionales.

## 3. Solution Developed

Se diseñó y ejecutó un conjunto de pruebas manuales bajo la metodología Black Box Testing.

Las actividades realizadas incluyeron:

- Exploración de categorías de productos.
- Validación de navegación.
- Comprobación del acceso al catálogo.
- Evaluación de la respuesta de las categorías.
- Validación del acceso al carrito.
- Documentación de resultados.
- Registro y evaluación de posibles defectos.

## 4. Testing Scope

Módulos evaluados:

- Product Catalog.
- Product Categories.
- Website Navigation.
- Shopping Cart.


## 5. Testing Methodology

Se utilizó Black Box Testing, evaluando el comportamiento observable del sistema sin consultar su implementación interna.

Técnicas aplicadas:

- Manual Testing.
- Functional Testing.
- Exploratory Testing.
- Positive Testing.
- UI Observation.

## 9. Defect Management

Durante los escenarios ejecutados no se confirmaron defectos funcionales.

Los comportamientos que inicialmente se consideraron candidatos de investigación fueron comprobados manualmente y no se reprodujeron como errores.

Por lo tanto, no se generaron reportes de bugs confirmados.

## 10. Business Value

La ejecución de pruebas funcionales permite comprobar que los elementos evaluados respondan correctamente y que los usuarios puedan acceder a las secciones correspondientes.

Este tipo de validación contribuye a:

- Mejorar la confiabilidad de la plataforma.
- Detectar posibles inconsistencias.
- Reducir riesgos funcionales.
- Evaluar la experiencia del usuario.
- Mantener un proceso documentado de aseguramiento de calidad.

## 11. Conclusion

El proyecto permitió aplicar conocimientos de QA en una plataforma comercial real, desarrollando escenarios de prueba, ejecutando validaciones manuales y documentando los resultados obtenidos.

La evaluación de los escenarios incluidos en el alcance finalizó sin defectos funcionales confirmados.

Este ejercicio demuestra la capacidad de analizar una plataforma, diseñar pruebas, validar resultados y documentar el comportamiento de un sistema desde la perspectiva del usuario.
